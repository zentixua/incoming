# Команды

[English](../commands.md) · Русский

Команда `/incoming` заказывает обычные удары и МБР и даёт инструменты администратора. Ядерную БЧ для крылатой
ракеты или B-2 она не выбирает: для этого нужен пульт. Аргумент сущности выбирает игрока или моба, а не заменяет
выбор аппарата пультом. У обычного игрока команда тратит боеприпасы и слушается
тех же [правил](rules.md), что пульт; у оператора и командного блока — нет.

Обычное `<оружие>`: `drone` (или `shahed`), `loiter` (`lancet`), `missile`, `rocket` (`grad`), `bunker`.
Отдельный синтаксис `nuke` — ниже: у него нет цели-сущности, формы `at <x z>` и команды залпа.

## Обычные удары

| Команда | Что делает |
|---|---|
| `/incoming <оружие>` | удар туда, куда смотришь |
| `/incoming <оружие> <игрок или моб>` | удар по цели |
| `/incoming <оружие> at <x z>` | удар по месту на земле; высоту сервер находит сам, как у места, выбранного [на карте](map.md) |
| `/incoming <оружие> at <x y z>` | удар точно в эту точку; над землёй снаряд взорвётся в воздухе, бомба упадёт на землю |
| `/incoming salvo <оружие> <число> <разброс> [цель]` | залп; цель — `me` (где стоишь, так по умолчанию), `look`, игрок или моб, `at <x z>` или `at <x y z>` |
| `… via <x z> [<x z> …]` | маршрут: до пяти точек, только для шахеда, ракеты и «Ланцета» |
| `… from <x z>` | место пуска: там (или на ближайшем открытом ровном месте в ~100 блоках) встанет пусковая и простоит до «Отбоя», а если такого нет, снаряды стартуют оттуда без неё (только оператор) |

`from` и `via` пишутся после цели залпа, сначала `from`. Один снаряд по маршруту — залп из одного: `salvo drone 1 0 …`.

## Ядерный удар

| Команда | Что делает |
|---|---|
| `/incoming nuke [кт [air\|ground]]` | МБР туда, куда смотришь |
| `/incoming nuke at <x y z> [кт [air\|ground]]` | МБР по точке |
| `/incoming nuke now [at <x y z>] [кт [air\|ground]]` | подрыв сразу, без полёта (только оператор) |

Без числа — `nuclear.default_yield` мира (по умолчанию 15 кт), воздушный подрыв. `air` или `ground` — только после
числа: `/incoming nuke 15 ground`.

## Прочее

| Команда | Что делает |
|---|---|
| `/incoming clear` | отбой своих обычных ударов; у оператора или хоста — всех ударов у всех, включая ядерные |
| `/incoming menu` | экран пульта |
| `/incoming help` | короткая справка в чате |
| `/incoming give [игроки]` | выдать пульт (только оператор) |
| `/incoming radiation [игрок]`, `radiation clear [игроки]` | доза облучения, снять облучение (только оператор) |

## Энергосеть

Только оператор. Координаты и номера узлов относятся к измерению команды; `status` и `restore` без аргументов
охватывают все измерения. Без координат используется твоё место, без радиуса — `grid.node_radius` (512 блоков).
Новые узлы и отключения ограничены `grid.max_radius` (по умолчанию 4096 блоков).

| Команда | Что делает |
|---|---|
| `/incoming grid status` | отключения, узлы и очередь обновления света во всех измерениях |
| `/incoming grid blackout [<x y z> [радиус]]` | обесточить район без подстанции; запрашиваемый радиус 16–16384 блока |
| `/incoming grid restore` | снять все отключения во всех измерениях |
| `/incoming grid restore at <x y z> <радиус>` | восстановить отключения, центры которых лежат в этом районе; радиус 1–1000000 блоков |
| `/incoming grid node add [<x y z> [радиус]]` | добавить узел сети без блока подстанции; запрашиваемый радиус 16–16384 блока |
| `/incoming grid node list` | узлы и их номера в этом измерении |
| `/incoming grid node remove <номер>` | удалить узел |
| `/incoming grid node knockout <номер>` | вывести узел из строя, как ударом |

Например, `/incoming grid blackout 100 64 -200 128` выбирает район вокруг X=100, Z=-200. Затем
`/incoming grid restore at 100 64 -200 128` начинает восстановление отключений с центрами не дальше 128 блоков от
этой точки. Во всех их кварталах свет возвращается за 10 секунд; восстановление не обрезается по границе круга.

## Стационарная пусковая

Только оператор. Пусковая должна стоять в загруженном чанке.

| Команда | Что делает |
|---|---|
| `/incoming launcher <x y z>` | состояние: задача, запас, последний сигнал |
| `… fire` | приказ по задаче, как сигнал редстоуна |
| `… mission <оружие> <число> <разброс> <x z> [via <x z> …]` | задача без правил игрока; цель — место на земле или, с `<x y z>`, точка |
| `… clear` | снять задачу |
| `… load <N>` | положить в запас N боеприпасов оружия задачи |
| `… owner <игрок>`, `owner none` | сменить хозяина или сделать пусковую ничьей |

Пусковая без хозяина (например, поставленная `/setblock`) стреляет без правил, как консоль.

## Примеры

```
/incoming missile Steve
/incoming salvo rocket 20 25 at 120 70 -340
/incoming salvo loiter 5 20 look
/incoming salvo drone 1 0 at 800 64 200 via 300 -100 600 -50
/incoming salvo missile 4 10 at 120 70 -340 from -900 400
/incoming nuke at 2000 64 0 1 ground
/incoming launcher 100 64 -20 mission missile 2 10 120 70 -340
```

1. Крылатая ракета по игроку Steve (если его видно).
2. Очередь «Града» из 20 снарядов с разбросом 25 блоков по точке.
3. Рой из пяти «Ланцетов» туда, куда смотришь.
4. Один шахед по точке, в обход через две точки маршрута.
5. Четыре крылатые ракеты по точке с пусковой у -900 400 (оператор).
6. Наземный ядерный подрыв 1 кт по точке.
7. Задача пусковой на 100 64 -20: две крылатые ракеты с разбросом 10 блоков по точке (оператор).
