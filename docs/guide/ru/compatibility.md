# Совместимость

[English](../compatibility.md) · Русский

Для Incoming нужны **Minecraft 1.21.1, NeoForge 21.1.264+ и Java 21**. Ни один из модов ниже не обязателен.
На сервере версия Incoming должна быть одинаковой у всех.

## Дополнительные моды

| Мод | Что даёт в Incoming | Куда ставить |
|---|---|---|
| Create | Крафт боеприпасов из деталей Create; без него рецепты используют ванильные предметы | Сервер и игроки |
| Create Aeronautics с Sable 2.0.6+ | Летающие аппараты можно брать на прицел, ломать и толкать взрывами | Сервер и игроки |
| Distant Horizons 3.3.3 | Дальний рельеф на карте и видимые издалека разрушения | Игроки; для обновления разрушений — также хост или выделенный сервер |
| Voxy через Roxy | Дальний рельеф на карте и в мире | Только игроки |
| LOD Server Support | Рельеф с сервера на карте наведения, даже без Voxy | Сервер и игроки; локальный мир нужно открыть для сети |
| Iris | Ядерные эффекты с шейдерами | Только игроки |
| Flashback | Запись и просмотр повторов с ударами | Только игроки |

## Voxy на NeoForge 1.21.1

Нужны [Roxy 0.4.1](https://modrinth.com/mod/roxy/version/VnJRhuAn) и **Fabric Voxy 0.2.16-beta для Minecraft 1.21.11**.
Это не опечатка: Roxy запускает эту версию на 1.21.1. Ещё ему нужны
[Sodium 0.8.12 для NeoForge 1.21.1](https://modrinth.com/mod/sodium/version/S3DUMfBo) и
[Forgified Fabric API 0.116.14+2.3.0 для 1.21.1](https://modrinth.com/mod/forgified-fabric-api/version/dAxle9F7).
Если не пользуешься Voxy, ничего из этого ставить не нужно.

Для LOD Server Support интеграция рассчитана на [NeoForge 0.19.0](https://modrinth.com/mod/lod-server-support/version/ydDRzPcM).
Если карта пустая, смотри [помощь с картой](map.md#если-карта-пустая).
Разрушения вдали могут появиться с задержкой — подробнее на странице [ядерного удара](nuke.md#что-будет).
Incoming приостанавливает свои обновления рельефа Voxy, пока соединение занято, и продолжает по мере его освобождения.
На медленном соединении изменения вдали появляются постепенно.
Эти версии не гарантируют, что любая комбинация модов и шейдеров будет работать без проблем.

## Другие моды на звук и взрывы

Sound Physics Remastered может добавлять повторное эхо к звукам Incoming. Если он установлен, исключи звуки
Incoming из его обработки. Подробности настройки — в [технической справке на английском](../../dev/integration-reference.md).

Если предпочитаешь эффекты другого мода, выключи **«Свои эффекты взрыва»** в настройках.
Это уберёт картинку и звук обычных взрывов Incoming, но не гарантирует замену эффектами другого мода.
Урон останется, а эффекты ПВО и ядерных ударов продолжат работать.
