# Вопросы и неполадки

[English](../faq.md) · Русский

## Что значит сообщение

| Сообщение | Что делать |
|---|---|
| «Не хватает боеприпасов…» | скрафти ещё или уменьши залп ([боеприпасы](munitions.md)) |
| «… не замечен…» | найди его глазами или камерой снаряда, или пусть его увидит команда ([разведка](rules.md#разведка)) |
| «Пусковую негде поставить…» | снаряд прилетит издалека; чтобы видеть пуск, отойди на открытое место |
| «Пуск не удался: рядом с целью мир не загружен» | боеприпас вернулся, попробуй ещё раз |
| «Цель не найдена» | цель дальше 400 блоков или под прицелом пусто: бей по карте |
| «… не пролетит маршрут…» | убери или сдвинь точки маршрута |
| «Пульт работает только у операторов» | так настроил хозяин мира |
| «Слишком много ударов в работе…» | хозяин мира поставил предел: дождись попаданий или дай [отбой](designator.md#отбой) |
| «Задача передана пусковым…» | к пульту привязаны [пусковые](launcher.md#задача); отвяжи их ПКМ пультом, чтобы он стрелял сам |

## Неполадки

**Не пускает на сервер: разные версии мода.** Скачай тот же jar, что на сервере, со страницы
[Releases](https://github.com/zentixua/incoming/releases): выбери точную версию сервера.
Последний выпуск нужен для совместного обновления сервера и всех клиентов.

**Карта вдали пустая.** Дальнему рельефу нужен LOD Server Support на сервере и у тебя, Voxy или Distant Horizons; без
них видны только загруженные чанки. Voxy показывает только то, что ты видел: в одиночной игре один раз набери
`/voxy import current`. Ударить туда всё равно можно. LOD Server Support стоял раньше этой версии? Один раз
набери `/lss clearcache` на том сервере.

**Не слышно звуков мода.** Проверь ползунок «Окружение».

**Тормозит при ударе.** Если дёргается только картинка, снизь качество «Гриб, стена пыли и пелена» или попробуй
без шейдеров. Если у всех замедляются мобы и редстоун, уменьши число одновременных ударов, особенно по неизведанной
местности. Владелец может изменить [настройки мира](settings.md#настройки-мира): более медленное разрушение оставляет
игре больше времени на остальное. Нужный объём памяти зависит от сборки.

**Пусковая или ЗРК не стреляет.** ПКМ пустой рукой покажет причину. ЗРК нужно открытое небо, ракеты на направляющих
и игрок рядом; свои снаряды, МБР и «Град» он не сбивает.

**Камера пишет «Нет снарядов в полёте».** Камера показывает только твои уже пущенные снаряды.

**Удар пришёл по своей базе.** Взрыв бьёт всех: перед огнём проверь цель на экране пульта. «Вокруг меня» бьёт туда,
где ты стоишь.
