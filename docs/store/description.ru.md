# Incoming: удары с воздуха и ПВО

Удары с воздуха, пульт наведения и оборона для Minecraft 1.21.1 на NeoForge.

**Minecraft 1.21.1 · NeoForge 21.1.264+ · Java 21 · нужен на сервере и у каждого игрока.**
Других обязательных модов нет. Версия Incoming на обеих сторонах должна совпадать.

![Крылатая ракета над городом](https://raw.githubusercontent.com/zentixua/incoming/main/docs/media/still-2.jpg)

## Как нанести удар

Скрафти пульт наведения и боеприпасы. Держи ПКМ для бинокля, колесом мыши выбери оружие, ЛКМ — пуск.
Shift+ПКМ открывает экран пульта; `,` — карту наведения. По умолчанию карта достаёт до 10 000 блоков и позволяет
задать до пяти точек маршрута дронам и крылатой ракете. `N` — камера снаряда, Shift — выход.

По умолчанию удары ломают блоки и поджигают горючее. Взрыв бьёт и запускающего. Ядерное оружие по умолчанию
только у операторов; хозяин мира задаёт доступ, разрушения и пожары отдельно для обычных и ядерных ударов.
Перед огнём рядом с постройкой проверь
[правила мира](https://github.com/zentixua/incoming/blob/main/docs/guide/ru/settings.md#настройки-мира).

## Оружие

| Оружие | Применение |
|---|---|
| Шахед-136 | Дрон с пуском с прицепа рядом; идёт за движущейся целью, пока она в его камере. |
| Ланцет | Барражирующий боеприпас: кружит над целью, затем выбираешь, что поразить, из его камеры. |
| Крылатая ракета | Низкий полёт над рельефом и пике в конце; может нести ядерную БЧ. |
| Град | Пусковая на 40 труб, неуправляемые ракеты по площади. |
| B-2 и бетонобойная бомба | Бомбардировщик сбрасывает управляемую бомбу: она проходит в грунт и взрывается под землёй; может нести ядерную БЧ. |
| МБР | Ядерный удар 1–15 кт, по умолчанию с таймером полёта 90 с. |

Один пуск тратит один предмет боеприпаса; пакет «Града» содержит 40 ракет. Залп оплачивается целиком при приказе,
невыпущенное возвращается при отбое или неудачном пуске. В творческом режиме боеприпасы не нужны.

У размеров снарядов блок равен метру. Разрушения считают модели заряда и материала с приближениями. Полёт и ПВО
при любом пресете используют игровую модель. GAME сохраняет полные радиусы ядерки, но замедляет дальнюю волну до
0,20 скорости звука; REAL даёт справочные скорости/высоты полёта и физическое время волны; CUSTOM может уменьшить
радиусы ядерки. См. [Не по физике](https://github.com/zentixua/incoming/blob/main/docs/guide/ru/not-physical.md).

## Тревога и оборона

У цели игроки слышат сирену и видят предупреждение. Блок ЗРК сбивает чужие шахеды, «Ланцеты», крылатые ракеты и
B-2, в том числе ядерные носители; ракеты «Града» и МБР не перехватывает. Четыре готовые направляющие пополняются
из двух ячеек запаса, по умолчанию по ракете за 8 секунд. Заряжай рукой или воронкой.

Стационарная пусковая выполняет задачу по сигналу редстоуна. Привяжи её к пульту, задай цель и положи боеприпасы.
Она берёт шахеды, «Ланцеты», обычные крылатые ракеты и «Град».

## Ядерный удар и блэкаут

У ядерного удара — вспышка, гриб и ударная волна, затем пожары. Наземный подрыв оставляет воронку и радиоактивный
след по ветру. Укройся под толщей грунта, отойди от окон и не смотри на шар. Счётчик Гейгера измеряет дозу и
мощность дозы. См. [выживание и радиацию](https://github.com/zentixua/incoming/blob/main/docs/guide/ru/nuke.md#как-выжить).

Если ядерка разрешена обычным игрокам, при ком-то ещё в сети пуску нужен второй ключ другого игрока рядом.
Обычный запускающий не может отозвать подтверждённый удар; оператор или хост может дать `/incoming clear`.

Выбитая подстанция гасит электрический свет своего района: по умолчанию 512 блоков, восстановление начинается
через 15 минут и идёт 90 секунд. Ядерному блэкауту подстанция не нужна, но каждое отключение ограничено
`grid.max_radius` (по умолчанию 4096 блоков), и у него свой переключатель.

## Необязательные моды

- **Create:** в рецептах детали Create; без него есть ванильные замены.
- **Create Aeronautics и Sable 2.0.6+:** выбор аппарата целью; взрывы ломают и толкают его блоки. Осколки пока проходят сквозь аппараты.
- **Distant Horizons 3.3+ с API 7:** дальний рельеф карты и обновление разрушений без посещения поддерживаемых чанков; обновления идут через очередь и асинхронную запись.
- **Voxy через Roxy (только клиенты):** дальний рельеф для картинки, наведения, лучей и звука. Roxy запускает оригинальный Fabric Voxy 0.2.16-beta для **Minecraft 1.21.11** на NeoForge 1.21.1; нужны также его зависимости Sodium и Forgified Fabric API.
- **LOD Server Support на сервере и клиентах:** рельеф сервера для карты, лучей и звука; в одиночной игре он не раздаёт мир, пока тот не открыт по сети.
- **Iris, Sound Physics Remastered и Flashback:** шейдеры, звуки мира и повторы. Для Incoming нужна настройка отдельных звуков Sound Physics.

[Точные версии, официальные ссылки и ограничения](https://github.com/zentixua/incoming/blob/main/README.ru.md#совместимость)

## Сервер и производительность

Конфиг сервера — `<level-name>/serverconfig/incoming-server.toml`: запусти один раз для создания, затем останови,
измени и запусти заново. У обычных и ядерных разрушений отдельные переключатели.

При долгом кадре снизь качество ядерного объёма или шейдеров. Если у всех замедляется серверный тик, уменьши
число одновременных приказов и дальних целей в неисследованном мире. Серверный бюджет `performance.work_ms_per_tick`
по умолчанию 30 мс (5–45): уменьшение оставляет больше времени тика на другую работу, разрушения заканчиваются позже.
Память зависит от сборки и сцены. См. [неполадки](https://github.com/zentixua/incoming/blob/main/docs/guide/ru/faq.md).
