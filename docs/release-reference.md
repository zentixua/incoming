# Historical release measurements

This reference preserves measurement details from archived release notes. These are historical results, not new measurements or performance guarantees for other systems.

## 3.8.0 smoke

In the scene bench with 100 strikes on an RTX 4060 at 2560×1600, GPU frame time in and around smoke was about 6–7 ms without a shader pack and about 16 ms with Complementary, compared with 20–89 ms in 3.7.0.

Player-visible behaviour and installation: [3.8.0 release notes](releases/3.8.0.md).
