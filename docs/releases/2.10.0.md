For Minecraft 1.21.1 and NeoForge 21.1.250 or newer. Not network-compatible with 2.9.0 and earlier: a player with an old version cannot join a server with the new one, so update the mod on the server and for every player.

## Changes

- Fixed launcher: a block loaded by hoppers and Create, assigned through the remote and fired by redstone.
- Salvo command: launch location (`from x z`), where the launcher sets up, and waypoints (`via x z …`), as on the remote map.
- Illustrated player guide with map GIFs: [docs/guide](https://github.com/zentixua/airstrike/blob/main/docs/guide/README.md).
- The game-master mod is now the separate [Almighty](https://github.com/zentixua/almighty) project and is no longer included in Airstrike releases. Airstrike now stores its own strike-command notes for the AI agent; Almighty presents them to the agent.

## Installation

Remove the old `airstrike-*.jar` from `mods` and put `airstrike-2.10.0.jar` in its place. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation). On the server, replace the old `airstrike-gm-*.jar` with `almighty-0.2.0.jar` from [Almighty releases](https://github.com/zentixua/almighty/releases); its settings, key and world rules are renamed as described in the Almighty 0.2.0 notes.

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.250 или новее. Не совместима по сети с 2.9.0 и более ранними версиями: игрок со старой версией не зайдёт на сервер с новой, поэтому мод нужно обновить на сервере и у всех игроков.

### Изменения

- Стационарная пусковая установка: блок, который заряжают воронки и Create, задачу ставит пульт, а стреляет он по сигналу редстоуна.
- Команда залпа: место пуска (from x z) — там встаёт пусковая, и точки маршрута (via x z …), как на карте пульта.
- Руководство игрока с картинками и GIF карты: [docs/guide](https://github.com/zentixua/airstrike/blob/main/docs/guide/README.md).
- Мод ведущего стал отдельным проектом [Almighty](https://github.com/zentixua/almighty) и в выпуски Airstrike больше не входит. Подсказки ИИ-агенту о командах ударов Airstrike теперь хранит у себя, Almighty показывает их агенту.

### Установка

Удалите из папки `mods` старый `airstrike-*.jar` и положите на его место `airstrike-2.10.0.jar`. Файл должен быть один и тот же на сервере и у всех игроков, подробности в [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка). Прежний мод ведущего `airstrike-gm-*.jar` на сервере заменяет `almighty-0.2.0.jar` из [выпусков Almighty](https://github.com/zentixua/almighty/releases); его настройки, ключ и правила мира переименовываются, как написано в заметках к Almighty 0.2.0.
