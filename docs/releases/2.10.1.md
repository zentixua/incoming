For Minecraft 1.21.1 and NeoForge 21.1.250 or newer. Not network-compatible with 2.10.0 and earlier: a player with an old version cannot join a server with the new one, so update the mod on the server and for every player.

## Changes

- The server no longer accumulates loaded chunks after many salvos. Target areas released after strikes now unload even when the server has no spare tick time. After about 60 salvos this could previously leave about 25,000 loaded chunks and reduce TPS to 13–15.
- The player guide is half as long, with animations instead of still images: [docs/guide](https://github.com/zentixua/airstrike/blob/main/docs/guide/README.md).

## Installation

Remove the old `airstrike-*.jar` from `mods` and put `airstrike-2.10.1.jar` in its place. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.250 или новее. Не совместима по сети с 2.10.0 и более ранними версиями: игрок со старой версией не зайдёт на сервер с новой, поэтому мод нужно обновить на сервере и у всех игроков.

### Изменения

- Сервер больше не копит загруженные чанки после множества залпов. Районы целей, которые мод отпускает после ударов, теперь выгружаются и тогда, когда у сервера в тике нет свободного времени. Раньше после примерно 60 залпов могло накопиться около 25 тысяч загруженных чанков, а TPS падал до 13–15.
- Руководство игрока стало вдвое короче, с анимациями вместо снимков: [docs/guide](https://github.com/zentixua/airstrike/blob/main/docs/guide/README.md).

### Установка

Удалите из папки `mods` старый `airstrike-*.jar` и положите на его место `airstrike-2.10.1.jar`. Файл должен быть один и тот же на сервере и у всех игроков, подробности в [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).
