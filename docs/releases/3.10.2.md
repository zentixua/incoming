For Minecraft 1.21.1 and NeoForge 21.1.264 or newer. Network protocol 49: update the server and every player to 3.10.2 before joining.

Nuclear strikes now use ground bursts by default, with a fix for the flat top of the dust column beneath an airburst.

## Main changes

- New designators and nuclear commands without a selected burst mode now use GROUND. Choose AIR in the designator or command for an airburst.
- The rising dust column beneath an airburst now has a billowing top instead of a flat cut. A gap between the dust column and mushroom cap is expected at the standard AIR burst height; a ground burst produces a connected column.

## Existing worlds

No server config edit is needed. Old designators without a stored burst mode become GROUND. Earlier versions could omit that field even after AIR was selected. Explicitly stored AIR settings and already scheduled ICBMs keep their mode.

## Installation

Replace `incoming-3.10.1.jar` in the `mods` folder with `incoming-3.10.2.jar`. Use NeoForge 21.1.264 or newer. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.264 или новее. Сетевой протокол 49: перед подключением обновите сервер и всех игроков до 3.10.2.

Ядерные удары теперь по умолчанию подрываются на земле. Исправлен плоский верх пылевой колонны под воздушным взрывом.

### Главное

- Новые пульты и ядерные команды без выбранного режима подрыва теперь используют GROUND. Для воздушного подрыва выберите AIR в пульте или команде.
- Верх поднимающейся пылевой колонны под воздушным взрывом теперь клубится, а не обрезается плоскостью. При стандартной высоте AIR между пылевой колонной и шляпкой ожидается зазор; при наземном взрыве колонна соединяется со шляпкой.

### Существующие миры

Править серверный конфиг не нужно. Старые пульты без сохранённого режима подрыва переходят на GROUND. Прежние версии могли не записывать это поле даже после выбора AIR. Явно сохранённый AIR и уже запланированные МБР сохраняют свой режим.

### Установка

Замените `incoming-3.10.1.jar` в папке `mods` на `incoming-3.10.2.jar`. Нужен NeoForge 21.1.264 или новее. Сервер и все игроки должны иметь один и тот же файл; см. [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).
