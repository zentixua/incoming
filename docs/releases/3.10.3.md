For Minecraft 1.21.1 and NeoForge 21.1.264 or newer. Network protocol 50: update the server and every player to 3.10.3 before joining.

The distant nuclear blast wave is faster by default.

## Main changes

- The GAME preset now moves the blast wave and its dust wall at 0.25 of the speed of sound instead of 0.20. The REAL preset still uses the true speed, and CUSTOM accepts 0.15–1.0 in `nuclear.wave_speed`.

## Existing worlds

Worlds on the GAME preset get the new speed with no config edit. Worlds on CUSTOM keep the `wave_speed` value in their `incoming-server.toml`. Detonations already in progress keep the speed they started with.

## Installation

Replace `incoming-3.10.2.jar` in the `mods` folder with `incoming-3.10.3.jar`. Use NeoForge 21.1.264 or newer. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.264 или новее. Сетевой протокол 50: перед подключением обновите сервер и всех игроков до 3.10.3.

Дальняя ударная волна ядерного взрыва по умолчанию стала быстрее.

### Главное

- В пресете GAME ударная волна и её пылевая стена теперь идут со скоростью 0,25 скорости звука вместо 0,20. Пресет REAL по-прежнему использует настоящую скорость, а CUSTOM принимает 0.15–1.0 в `nuclear.wave_speed`.

### Существующие миры

Миры на пресете GAME получают новую скорость без правки конфига. Миры на CUSTOM сохраняют значение `wave_speed` из своего `incoming-server.toml`. Уже идущие взрывы сохраняют скорость, с которой начались.

### Установка

Замените `incoming-3.10.2.jar` в папке `mods` на `incoming-3.10.3.jar`. Нужен NeoForge 21.1.264 или новее. Сервер и все игроки должны иметь один и тот же файл; см. [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).
