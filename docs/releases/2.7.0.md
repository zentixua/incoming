For Minecraft 1.21.1 and NeoForge 21.1.250 or newer. Not network-compatible with 2.6.0 and earlier: a player with an old version cannot join a server with the new one, so update the mod on the server and for every player.

## Changes

- The open targeting map builds distant Distant Horizons terrain several times faster.
- Nuclear strikes on old maps (Greenfield, Project Zearth and others upgraded from earlier game versions) prepare ruins during ICBM flight. After teleporting into the strike zone, ruins near the player are placed first.

## Fixes

- Cruise missiles, Shaheds and Grad rockets no longer crash during acceleration into obstacles ahead of a launcher slot or above the launch line: such launcher locations are no longer chosen.
- Launcher search in dense buildings has a per-tick work limit and no longer stalls the server. If no location is found within the budget, projectiles approach from afar, as when no suitable location exists.

## Installation

Remove the old `airstrike-*.jar` from `mods` and put `airstrike-2.7.0.jar` in its place. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.250 или новее. Не совместима по сети с 2.6.0 и более ранними версиями: игрок со старой версией не зайдёт на сервер с новой, поэтому мод нужно обновить на сервере и у всех игроков.

### Изменения

- Карта наведения строит дальний рельеф Distant Horizons в несколько раз быстрее, пока она открыта.
- Ядерный удар по старым картам (Greenfield, Project Zearth и другим, обновлённым с прежних версий игры) строит руины заранее, пока летит МБР. После телепорта в зону удара руины рядом с игроком встают первыми.

### Исправления

- Крылатые ракеты, шахеды и «Грады» больше не разбиваются на разгоне о то, что стоит на пути одной из ячеек пусковой или над линией взлёта: такое место для пусковой больше не выбирается.
- Поиск места для пусковой в плотной застройке ограничен по объёму работы за тик и больше не задерживает сервер. Если место в этих пределах не нашлось, снаряды заходят на цель издалека, как и тогда, когда места нет вовсе.

### Установка

Удалите из папки `mods` старый `airstrike-*.jar` и положите на его место `airstrike-2.7.0.jar`. Файл должен быть один и тот же на сервере и у всех игроков, подробности в [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).
