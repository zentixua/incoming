For Minecraft 1.21.1 and NeoForge 21.1.250 or newer. Not network-compatible with 2.10.2 and earlier: a player with an old version cannot join a server with the new one, so update the mod on the server and for every player.

## Changes

Strikes no longer load the server where nobody can see them. In a Project Zearth test with six players in different cities, a game-master campaign across the map (265 salvos, 569 projectiles) previously cost as much server tick time as the players themselves; now it is barely visible in the profile.

- A projectile unseen by every player no longer drags loaded chunks across the map. At its chunk's edge it continues outside the world; players see its path as they already saw distant projectiles. Near players it flies in the world as before.
- Target areas preload but tick (mobs, mechanisms and spawning) only during the last 8 seconds of approach. Lancets circle in a ticking area as before.
- Heavy mod work (craters, glass, nuclear ruins, blackout) uses spare tick time. On a busy server the mod takes about 2 ms per work item instead of adding the former 30 ms. Destruction takes longer to finish, but the game does not slow down. `performance.work_ms_per_tick` is now a ceiling.

## Installation

Remove the old `airstrike-*.jar` from `mods` and put `airstrike-2.10.3.jar` in its place. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.250 или новее. Не совместима по сети с 2.10.2 и более ранними версиями: игрок со старой версией не зайдёт на сервер с новой, поэтому мод нужно обновить на сервере и у всех игроков.

### Изменения

Удары больше не нагружают сервер там, где их никто не видит. На копии Project Zearth с шестью игроками в разных городах кампания ведущего по всей карте (265 залпов, 569 снарядов) раньше отнимала у тика сервера столько же, сколько сами игроки; теперь в профиле её почти не видно.

- Снаряд, которого не видит ни один игрок, больше не тянет за собой загруженные чанки через всю карту. Дойдя до края своего чанка, он летит дальше вне мира, а игроки видят его путь так же, как раньше видели далёкие снаряды. Рядом с игроками снаряд летит в мире, как прежде.
- Район цели заранее только грузится, а тикает (мобы, механизмы, спавн) лишь последние 8 секунд подлёта. «Ланцет» кружит над целью в тикающем районе, как раньше.
- Тяжёлая работа мода (воронки, стёкла, руины ядерки, блэкаут) идёт во время, свободное в тике. Если сервер и так не успевает, мод берёт около 2 мс на каждую работу, а не прежние 30 мс сверху. Разрушения на занятом сервере достраиваются дольше, зато игра не замедляется. Настройка `performance.work_ms_per_tick` теперь задаёт потолок.

### Установка

Удалите из папки `mods` старый `airstrike-*.jar` и положите на его место `airstrike-2.10.3.jar`. Файл должен быть один и тот же на сервере и у всех игроков, подробности в [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).
