For Minecraft 1.21.1 and NeoForge 21.1.264 or newer. Network protocol 51: update the server and every player to 3.10.4 before joining.

Nuclear ruins now reach the whole saved world, so maps and distant terrain show the full damage area.

## Main changes

- After the blast wave has crossed the ruin zone, the server applies ruins and the ground trace to every existing chunk in that zone in the background, starting from ground zero and moving outward. Before, chunks outside the heavy-damage zone stayed intact on disk until a player came near, so maps that read the saved world (Xaero's World Map with a server map cache, LOD Server Support, Voxy, our targeting map) showed a straight edge around the first kilometer.
- The pass shares the server's work budget and backs off when the server is busy or memory is short; ruins in players' view go first. In our test, the zone of a 7 kt strike over a large city took about an hour.
- The pass continues after a server restart.

## Existing worlds

Nuclear strikes saved by older versions are caught up automatically after the update: the server starts the same pass for them on its own.

## Installation

Replace `incoming-3.10.3.jar` in the `mods` folder with `incoming-3.10.4.jar`. Use NeoForge 21.1.264 or newer. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.264 или новее. Сетевой протокол 51: перед подключением обновите сервер и всех игроков до 3.10.4.

Ядерные руины теперь доходят до всего сохранённого мира, поэтому карты и дальняя прорисовка показывают всю зону разрушений.

### Главное

- Когда ударная волна пройдёт зону разрушений, сервер в фоне применяет руины и след на земле ко всем существующим чанкам этой зоны, от эпицентра наружу. Раньше чанки за зоной тяжёлых разрушений оставались целыми на диске, пока рядом не появится игрок, и карты, которые читают сохранённый мир (Xaero's World Map с серверным кэшем карты, LOD Server Support, Voxy, наша карта целей), показывали прямую границу примерно в километре от взрыва.
- Проход делит рабочий бюджет сервера и замедляется, когда сервер занят или мало памяти; руины в поле зрения игроков идут первыми. В нашем тесте зона удара 7 кт по большому городу заняла около часа.
- Проход продолжается после перезапуска сервера.

### Существующие миры

Ядерные удары, сохранённые старыми версиями, догоняются сами после обновления: сервер сам запускает для них такой же проход.

### Установка

Замените `incoming-3.10.3.jar` в папке `mods` на `incoming-3.10.4.jar`. Нужен NeoForge 21.1.264 или новее. Сервер и все игроки должны иметь один и тот же файл; см. [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).
