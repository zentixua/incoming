For Minecraft 1.21.1 and NeoForge 21.1.264 or newer. Network protocol 48: clients of 3.10.0 and earlier cannot join a server running 3.10.1, so update the mod on the server and for every player.

A fix for players being disconnected from a server after a nuclear strike.

## Main changes

- After a nuclear strike, players with Voxy no longer drop off the server with a timeout. The server sent all distant terrain changes at once, the connection fell behind and missed its keep-alive; now it sends them in batches at the pace the player's connection actually receives them.

## Installation

Replace `incoming-3.10.0.jar` in the `mods` folder with `incoming-3.10.1.jar`. Use NeoForge 21.1.264 or newer. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

<details>
<summary>Change details</summary>

### Changes

- Voxy terrain updates go out in batches: the next batch waits until the client confirms the previous one, the batch size follows the client's measured receive rate, and delivery pauses while the connection is busy. On a slow connection, distant changes arrive gradually instead of all at once.
- The client confirms a batch only after Voxy has processed it, so a busy Voxy also slows delivery. Fresh chunk changes are kept through chunk unloading and repeated saves.

</details>

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.264 или новее. Сетевой протокол 48: клиенты 3.10.0 и раньше не зайдут на сервер с 3.10.1, поэтому обновите мод на сервере и у всех игроков.

Исправление вылетов игроков с сервера после ядерного удара.

### Главное

- После ядерного удара игроки с Voxy больше не вылетают с сервера по тайм-ауту. Сервер отправлял все изменения дальнего рельефа разом, соединение не успевало и пропускало проверку связи; теперь он шлёт их порциями с той скоростью, с которой соединение игрока их действительно принимает.

### Установка

Замените `incoming-3.10.0.jar` в папке `mods` на `incoming-3.10.1.jar`. Нужен NeoForge 21.1.264 или новее. Сервер и все игроки должны иметь один и тот же файл; см. [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).

<details>
<summary>Подробности изменений</summary>

#### Изменения

- Обновления рельефа для Voxy уходят порциями: следующая ждёт, пока клиент подтвердит предыдущую, размер порции следует измеренной скорости приёма у клиента, а пока соединение занято, отправка стоит. На медленном соединении дальние изменения приходят постепенно, а не все разом.
- Клиент подтверждает порцию только после того, как Voxy её обработал, так что занятый Voxy тоже замедляет отправку. Свежие изменения чанков сохраняются при выгрузке чанков и повторных сохранениях.

</details>
