For Minecraft 1.21.1 and NeoForge 21.1.250 or newer. Not network-compatible with 2.8.0 and earlier: a player with an old version cannot join a server with the new one, so update the mod on the server and for every player.

## Changes

- Canceling a large salvo no longer freezes the server for seconds. Target areas held by the mod are released in sequence instead of in one tick; such a tick could previously take 6.8 s.
- Debris entering an unticked area disappears instead of hanging in the air. Debris and spent boosters are no longer saved with the world; they could previously accumulate to over 10,000. Existing saved debris is omitted when its chunks next unload.
- If the server stalls for more than 2 seconds, its log reports “Поток сервера стоял …” with the location of the stall, helping find rare long pauses that disconnect players.

## Installation

Remove the old `airstrike-*.jar` from `mods` and put `airstrike-2.8.1.jar` in its place. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.250 или новее. Не совместима по сети с 2.8.0 и более ранними версиями: игрок со старой версией не зайдёт на сервер с новой, поэтому мод нужно обновить на сервере и у всех игроков.

### Изменения

- После Отбоя большого залпа сервер больше не замирает на несколько секунд. Районы целей, которые мод держал загруженными, теперь отпускаются по очереди, а не все в одном тике; раньше такой тик мог длиться 6,8 с.
- Обломки, улетевшие туда, где мир не обновляется, исчезают, а не висят в воздухе. Обломки и отработавшие ускорители больше не записываются в сохранение мира; раньше их могло накопиться больше 10 тысяч. Обломки, которые уже лежат в сохранении, при следующей выгрузке своих чанков в него не попадут.
- Если сервер стоит дольше 2 секунд, в его лог пишется строка «Поток сервера стоял …» с местом, где он стоял. Это поможет найти причину редких долгих остановок, из-за которых отключаются игроки.

### Установка

Удалите из папки `mods` старый `airstrike-*.jar` и положите на его место `airstrike-2.8.1.jar`. Файл должен быть один и тот же на сервере и у всех игроков, подробности в [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).
