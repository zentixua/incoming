For Minecraft 1.21.1 and NeoForge 21.1.264 or newer. Network protocol 56: clients of 3.12.0 and earlier cannot join a server running 3.12.1, so update the mod on the server and for every player.

Countdowns tick every second again, in any world.

## Main changes

- **Countdowns in old worlds.** In a world that has been running for a long time, the time to detonation stood still for up to 6.4 seconds and then jumped: the HUD added the frame's fraction of a tick to the world's game time with too little precision. On a world about 2 billion ticks old the step was 6.4 seconds; on one about 260 million ticks old it was 0.8 seconds. The countdown now changes every second in any world. The flashing "MISSILE ATTACK" warning and the warhead streak in old Flashback recordings had the same fault and are fixed too.
- **Whole seconds again.** Time to detonation and time to impact show whole seconds again, as before 3.12.0. They still never jump back when a server packet arrives late.

## Installation

Replace `incoming-3.12.0.jar` in the `mods` folder with `incoming-3.12.1.jar`. Use NeoForge 21.1.264 or newer. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.264 или новее. Сетевой протокол 56: клиенты 3.12.0 и раньше не зайдут на сервер с 3.12.1, поэтому обновите мод на сервере и у всех игроков.

Таймеры снова идут каждую секунду в любом мире.

### Главное

- **Таймеры в старых мирах.** В мире, который идёт давно, время до подрыва стояло до 6,4 секунды и потом прыгало: интерфейс прибавлял долю тика текущего кадра к игровому времени мира со слишком малой точностью. В мире возрастом около 2 миллиардов тиков шаг был 6,4 секунды, в мире около 260 миллионов тиков — 0,8 секунды. Теперь отсчёт меняется каждую секунду в любом мире. Та же ошибка была у мигающего «РАКЕТНОЕ НАПАДЕНИЕ» и у следа боеголовки в старых записях Flashback, они тоже исправлены.
- **Снова целые секунды.** Время до подрыва и время до удара снова показываются в целых секундах, как до 3.12.0. Назад, когда пакет сервера приходит с опозданием, они по-прежнему не прыгают.

### Установка

Замените `incoming-3.12.0.jar` в папке `mods` на `incoming-3.12.1.jar`. Нужен NeoForge 21.1.264 или новее. Сервер и все игроки должны иметь один и тот же файл; см. [README](https://github.com/zentixua/incoming/blob/main/README.ru.md#установка).
