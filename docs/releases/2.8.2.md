For Minecraft 1.21.1 and NeoForge 21.1.250 or newer. Network-compatible with 2.8.1: players using 2.8.1 do not need to update.

## Changes

Airstrike itself is unchanged. This release adds a second file, `airstrike-gm-0.1.0.jar`, a server-only game-master mod. Through it, an AI game master:

- sees the world: an overhead map, a view from any point, blocks, entities and game events;
- places buildings with rollback and runs commands;
- runs server scripts and rules responding to game events in the same tick.

The game-master mod adds no blocks, items or packets, so players do not need it. Connections work only from the same computer or the host's private network and require a key.

## Installation

No change is needed: `airstrike-2.8.1.jar` works with 2.8.2. Place the game-master mod in the server's `mods` folder alongside Airstrike. On first start it creates a key at `config/airstrike_gm/token`.

## Русский

Для Minecraft 1.21.1 и NeoForge 21.1.250 или новее. Совместима по сети с 2.8.1: игроку с 2.8.1 обновляться не обязательно.

### Изменения

В самом Airstrike изменений нет. Выпуск нужен ради второго файла, `airstrike-gm-0.1.0.jar`. Это мод ведущего, который ставится только на сервер. Через него ИИ-ведущий ведёт игру:

- видит мир: карту сверху, вид с любой точки, блоки, сущности и события игры;
- ставит постройки с откатом и выполняет команды;
- запускает на сервере свои скрипты и правила, которые отвечают на события игры в том же тике.

Мод ведущего не добавляет блоков, предметов и пакетов, поэтому игрокам его ставить не нужно. Связь с ним работает только с того же компьютера или из закрытой сети хоста и требует ключа.

### Установка

Ничего менять не нужно: `airstrike-2.8.1.jar` работает вместе с 2.8.2. Мод ведущего кладут в папку `mods` сервера рядом с Airstrike. При первом запуске он создаёт ключ в `config/airstrike_gm/token`.
