# AGENTS.md — для агентов кроме Claude Code (Codex и других)

Правила проекта — в `CLAUDE.md` в корне и в файлах областей `.claude/rules/`. Они общие для всех, кто работает над
модом, человек это или агент; здесь — только как их брать и чем работа другого агента отличается.

- Перед работой прочитай `CLAUDE.md` целиком: люди, принципы физики и подачи, рабочий цикл, проверки, общие правила
  кода.
- Файлы областей сами не подгружаются. Перед правкой открой файл области, чьи `paths:` (шапка файла) покрывают файлы,
  которые ты меняешь; список областей — в конце `CLAUDE.md`. Планируешь работу, ещё не открыв файлов, — прочитай файл
  области по её описанию там же.
- Где `CLAUDE.md` называет инструменты Claude Code (Read, Edit, Write) или его настройки (`.claude/settings.json`) —
  это о Claude Code; правило за ними то же и для тебя.

Чем отличается:
- Независимое ревью делает другая сессия или другая модель, не автор. Ревьюер получает только дифф и записку PR, без
  разговора и выводов автора, и сверяет код с запиской.
- Коммит кончается строкой `Co-Authored-By:` своего агента (его имя и адрес), не чужой.
