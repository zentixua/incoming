# Security policy

Security fixes target the latest published Incoming release for Minecraft
1.21.1 / NeoForge. Reproduce a suspected issue on that release when possible.

Do not post exploit instructions, credentials or private logs in a public issue.
Use GitHub's **Report a vulnerability** button on the repository's
[Security page](https://github.com/zentixua/incoming/security) if it is available.
Private vulnerability reporting is not currently enabled. Until it is enabled,
open an [issue](https://github.com/zentixua/incoming/issues/new) titled
**Security contact request**, without technical or sensitive details, so the
maintainer can arrange a private channel before you share the report.

In the private report, include affected versions, reproduction steps, impact and
any workaround. No response time is guaranteed.
