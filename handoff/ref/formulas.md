# Законы: формулы, единицы, источники

Отметки: **✓ код** — уже в коде мода и покрыт тестом; **✓ сверено** — сверено по первоисточнику при подготовке
пакета; **⚠ сверить** — записано по названному источнику по памяти: сверить с ним до кода, расхождение — поправить
здесь и сказать Артёму. Единицы СИ, если не сказано иное; блок = метр, тик = 1/20 с.

## 1. Атмосфера (шаг 1)

- **Стандартная атмосфера ISO 2533** (⚠ сверить): до 11 км T = 288.15 − 0.0065·h, p = 101 325·(T/288.15)^5.2559;
  11–20 км T = 216.65, p = 22 632·exp(−(h − 11 000)/6341.6); ρ = p/(287.05·T); скорость звука a = √(1.4·287.05·T).
- **Профиль ветра у земли** (⚠ сверить): логарифмический u(z) = (u*/κ)·ln(z/z₀), κ = 0.4, z₀ по местности (трава
  0.03 м, лес и город 0.5–1 м); или степенной u = u_ref·(z/z_ref)^α, α ≈ 0.1 днём (неустойчиво), 0.14 нейтрально,
  0.3–0.4 ночью (устойчиво).
- **Устойчивость** (⚠ сверить): классы Паскуилла A–F по ветру у земли, солнцу днём и облачности ночью (таблица
  Паскуилла–Гиффорда). Частота Брента–Вяйсяля N² = (g/θ)·dθ/dz: стандартная атмосфера N ≈ 0.012 с⁻¹, ночная инверсия
  0.02–0.04 с⁻¹.
- Погода игры (дождь, гроза, время суток) задаёт класс устойчивости и влажность; направление и сила ветра — общая модель
  на мир (сейчас ветер есть только у ядерки: случайный на подрыв, `Detonation.windDir/windSpeed`).

## 2. Движение (шаг 2)

- **Точка с массой**: m·dv/dt = T(t) − D − m·g; D = ½·ρ·v²·CdA·f(M); расход ṁ = T/(Isp·g₀) у ракетных двигателей
  (твёрдое топливо Isp ~230–250 с — ⚠ уточнить по изделию), у ТРДД — по удельному расходу. Образец уже в коде:
  `WeaponSpec.Ascent` (✓ код, «Минитмен»).
- **Кривая сопротивления f(M)** для оперённых тонких тел без опубликованных продувок (О, типовая форма, `tools/flight.py`):
  1.0 до М0.8; линейно до 1.8 к М1.05; 1.8 до М1.2; дальше спадает на 0.45 на единицу М, не ниже 1.1.
- **Винт**: тяга T = η·P/v (η — КПД винта 0.6–0.8); электромотор и поршень — мощность с ТТХ.
- **Поворот**: перегрузка n = v·ω/g, крен tan φ = v·ω/g; пределы — из ТТХ, где они есть, иначе оценка с отметкой.
  `FlightController.bankAngle` сейчас берёт g = 0.08 блока/тик² (значение Minecraft) вместо 0.0245 (9.8 м/с²).
- **Сила тяжести**: 9.80665 м/с² = 0.0245 блока/тик².

## 3. Волна взрыва (шаг 5)

Приведённое расстояние Z = R/W^⅓ (м/кг^⅓); у земли W → 1.8·W.

- **Давление** (Кинни–Грэхем, «Explosive Shocks in Air», 1985; ✓ код `BlastModel.surfaceOverpressureKpa`):
  P/P₀ = 808·(1 + (Z/4.5)²) / √((1 + (Z/0.048)²)·(1 + (Z/0.32)²)·(1 + (Z/1.35)²)), P₀ = 101.325 кПа.
- **Длительность фазы сжатия** (там же; ⚠ сверить — в коде есть только `positivePhaseSeconds(kt)`):
  t₊/W^⅓ [мс] = 980·(1 + (Z/0.54)^10) / ((1 + (Z/0.02)³)·(1 + (Z/0.74)^6)·√(1 + (Z/6.9)²)).
- **Импульс** (там же; ⚠ сверить): I/W^⅓ [бар·мс] = 0.067·√(1 + (Z/0.23)^4) / (Z²·(1 + (Z/1.55)³)^⅓).
- **Давление–импульс** (UFC 3-340-02, 2008; Baker и др.; ⚠ сверить): элемент разрушается, если
  (P − P_c)·(I − I_c) ≥ k; P_c — нынешний порог блока в psi (`BlockResponse`), I_c — порог импульса, подбирается так,
  чтобы радиусы Джаррета (ниже) для кирпичных и деревянных домов выходили сами. У ядерной волны импульс на порядки
  больше I_c — ответ ядерки не меняется (тест).
- **Джаррет** (Annals NY Acad. Sci. 152, 1968; ⚠ сверить коэффициенты): R = K·W^⅓ / (1 + (3175/W)²)^(1/6), W кг ТНТ,
  R м; K: A (почти полный снос) 3.8, B (снос, 50–75% наружных стен) 5.6, Cb (непригоден для жилья) 9.6, Ca (умеренные)
  28, D (лёгкие: окна, черепица) 56. В пакете «сильные» = Cb, «снос» = B.
- **Газы в помещении** (UFC 3-340-02; ⚠ сверить): квазистатическое давление P_qs ≈ 2.25·(W/V)^0.72 МПа (W кг ТНТ,
  V м³ свободного объёма), спадает через проёмы. Взрыв внутри комнаты держит давление на всех стенах, а не только
  на ближних.
- **Скоростной напор и бросок** (✓ код): `BlastModel.dynamicPressureKpa`, `Detonation.throwSpeed(kpa)`. Для короткой
  волны бросок — от импульса: Δv ≈ C_d·A·I_q/m (тело не успевает набрать скорость за t₊).

## 4. Воронка, обломки, бомба (шаги 5, 9)

- **Воронка поверхностного заряда в грунте** (Ambrosini, Luccioni и др.; ⚠ сверить): D ≈ (0.51–0.8)·W^⅓ м; глубина
  ~¼ диаметра. Ядерный `CraterModel` (23·Y^0.3) для обычных зарядов не годится.
- **Пробитие Янга** (C. W. Young, «Penetration Equations», Sandia SAND97-2426, 1997, прил. A; ✓ сверено, PDF в `refs/`):
  - V ≥ 61 м/с: D = 0.000018·S·N·(m/A)^0.7·(V − 30.5); V < 61 м/с: D = 0.0008·S·N·(m/A)^0.7·ln(1 + 2.15·10⁻⁴·V²).
    D — путь, м; m кг; A — площадь сечения, м²; V м/с.
  - Лёгкий снаряд: грунт K_s = 0.27·m^0.4 при m < 27 кг; камень и бетон K_h = 0.46·m^0.15 при m < 182 кг (множитель D).
  - Нос: оживало N = 0.18·L_n/d + 0.56 или N = 0.18·√(CRH − 0.25) + 0.56; конус N = 0.25·L_n/d + 0.56; плоский 0.56.
  - S камня: S = 2.7·(f_c·Q)^−0.3 (f_c — прочность на сжатие, МПа; Q — качество 0.1–0.9: массив 0.9, трещиноватый 0.4,
    сильно трещиноватый 0.2).
  - S бетона: S = 0.085·K_e·(11 − P)·(t_c·T_c)^−0.06·(35/f_c)^0.3 (P — % арматуры по объёму; t_c — лет, ≤1; T_c —
    толщина в калибрах, 0.5–6, больше 6 → 6; K_e = 1 у широкой цели); без данных S = 0.9.
  - S грунта (табл. 4-2): плотный сухой сцементированный песок 2–4; гравий, песок, очень жёсткая сухая глина 4–6;
    рыхлый и средний песок 6–9; насыпь 8–10; жёсткие ил и глина 5–10; влажные ил и глина, рыхлая почва 10–20; мягкая
    насыщенная глина 20–30. Лёд 4.5 — своя формула (A-3.6). Фанера пачкой 1.5; валуны 2–3; щебень 2–4.
  - Слои (разд. 6): в слое толщины T при угле θ к поверхности средняя перегрузка a = V²/(2·g·D), скорость на выходе
    V_ex = √(V² − 2·g·a·T/sin θ) = V·√(1 − T/(D·sin θ)); у грунта под бетоном и между плитами S вдвое меньше (до 6
    калибров). Точность: уравнение ~15%, с S бетона 15–20%, скалы — от 20% до 2 раз.
  - Блоки Minecraft → S (О, первая раскладка; сверить на шаге 9): камень, андезит, диорит, гранит S ≈ 0.84 (f_c 100,
    Q 0.5); глубинный сланец 0.67 (f_c 150, Q 0.7); туф, кальцит ~1.2; бетон 0.84; кирпич и каменный кирпич ~1.0;
    обсидиан ~0.6; земля и трава 10–15; песок 6–9; гравий 4–6; глина 5–10; лёд 4.5 (формула льда); доски 1.5; воздух и
    вода — не по Янгу (пустота: датчик, вода — сопротивление жидкости).
- **Запертый взрыв** (TM 5-855-1, Westine; ⚠ сверить): радиус каверны ~0.12–0.5·W^⅓ м (между ядерными и ВВ-данными,
  широкая оценка), зона дробления — несколько радиусов каверны, трещины и обрушения ходов — десятки метров; выброс на
  поверхность, если приведённая глубина d/W^⅓ меньше ~1 м/кг^⅓ (иначе — только вспучивание и пыль из хода).

## 5. Огонь, дым, следы (шаги 4, 7, 10)

- **Шар взрывчатки** (✓ код `FarBlasts`, ⚠ сверить источник): радиус ≈ 1.7·W^⅓ м, свечение ~0.2·W^0.35 с, ~2500–3500 K.
- **Шар топлива** (CCPS 1994, TNO; ⚠ сверить): D = 5.8·M^⅓ м, t = 0.45·M^⅓ с (M кг топлива, до 30 т); поверхностная
  излучаемая мощность ~200–350 кВт/м²; температура ~1100–1400 K.
- **Цвет и яркость огня** (✓ код `BlackBody`): Планк × приближение Wyman–Sloan–Shirley, табулировать.
- **Всплытие тёплого облака** (Morton, Taylor, Turner, Proc. R. Soc. A 234, 1956; ⚠ сверить коэффициенты): мгновенное
  тепло Q даёт плавучесть B = g·Q/(ρ·c_p·T) (м⁴/с²); высота в стратифицированном воздухе z_max ≈ 2.66·B^¼·N^−½;
  радиус клуба растёт ~0.25·z (вовлечение). Тепло ТНТ ~4.2 МДж/кг (с догоранием сажи больше), топлива ~43 МДж/кг.
- **Непрерывный источник** (пожар, факел на старте; MTT, Briggs; ⚠ сверить): без ветра z_max ≈ 5.0·F^¼·N^−¾ (F —
  поток плавучести, м⁴/с³); в ветре подъём Бриггса Δh = 1.6·F^⅓·x^⅔/u.
- **Расплывание следа** (Паскуилл–Гиффорд, формулы Бриггса для открытой местности; ⚠ сверить), x = u·t:
  A: σ_y = 0.22x(1+0.0001x)^−½, σ_z = 0.20x; B: 0.16x(…)^−½, 0.12x; C: 0.11x(…)^−½, 0.08x(1+0.0002x)^−½;
  D: 0.08x(…)^−½, 0.06x(1+0.0015x)^−½; E: 0.06x(…)^−½, 0.03x(1+0.0003x)^−1; F: 0.04x(…)^−½, 0.016x(1+0.0003x)^−1.
  На высоте, где нет земли, — та же диффузия по времени.
- **Инверсионный след** (Шмидт–Эпплман, Schumann 1996; ⚠ сверить): G = EI_H₂O·c_p·p / (ε·Q·(1 − η)) (EI 1.25 для
  керосина, Q 43.2 МДж/кг, ε 0.622, η — полный КПД 0.3–0.4); пороговая температура
  T_LM ≈ −46.46 + 9.43·ln(G − 0.053) + 0.72·(ln(G − 0.053))² °C (G в Па/К); след стоит, если воздух холоднее и влажнее
  порога (долго — при пересыщении надо льдом).
- **Оптика дыма** (⚠ сверить, литературные значения): массовое ослабление сажи ~7.5–10 м²/г (550 нм, Bond и Bergstrom
  2006), альбедо однократного рассеяния сажи 0.2–0.3, пыли грунта ~0.9, белого дыма твёрдого топлива (Al₂O₃) ~0.99;
  τ = σ_m·∫ρ·dl, пропускание e^−τ (Бугер–Ламберт–Бер), фаза рассеяния — Хеньи–Гринстейн (g ≈ 0.6–0.8 вперёд). Доля
  сажи у тротила — уточнить (тротил беден кислородом: дым чёрный; гексогеновые составы — серый).

## 6. Звук (шаги 3, 8)

- **Распространение** (✓ код): ISO 9613-1 (поглощение воздухом, таблица в `tools/build_sounds.py`), ISO 9613-2 в двух
  полосах (`Outdoor`), заслон (`Occlusion`), фильтры EFX (`SoundFilters`).
- **Источник**: уровень мощности L_W = 10·lg(W_ак/10⁻¹²). РДТТ: W_ак ≈ η·½·ṁ·v_e², η ~0.5% (NASA SP-8072; ⚠ сверить).
  Винт: частота лопастей BPF = B·n/60 и гармоники; поршень: частота вспышек = n/60 × цилиндры (двухтакт) или
  ×цилиндры/2 (четырёхтакт). ТРДД: шум струи и тон вентилятора; громкость по записям с известным расстоянием.
  Записи выравниваются к уровню источника, а слышимость получается из распространения, а не постоянной.
- **Доплер** (✓ код): f′ = f·c/(c − v_r).
- **Сверхзвук** (⚠ сверить): угол конуса sin μ = 1/M; запаздывание — два корня уравнения t_e = t − |p(t_e) − L|/c
  (внутри конуса); N-волна — упрощённый метод Карлсона (NASA TP-1122, 1978) для давления и длительности.
- **Звук взрыва по заряду** (Сакс; ⚠ сверить): время × (W/W₀)^⅓, высота тона × (W₀/W)^⅓; давление — из волны (§3).
- **Оглушение** (✓ код у ядерки, `Deafness`): по давлению у слушателя.

## 7. Осколки (шаг 6)

- **Скорость Герни** (⚠ сверить): цилиндр V₀ = √(2E)·√((C/M)/(1 + C/(2M))), √(2E) ≈ 2.4–2.8 км/с (ТНТ — гексогеновые
  составы); C — масса ВВ, M — масса корпуса.
- **Распределение масс** (Мотт; ⚠ сверить): N(>m) = N₀·exp(−√(m/μ)).
- **Торможение**: v(x) = V₀·exp(−x/L), L = 2m/(ρ·C_d·A), A ≈ k·m^⅔ (форма осколка).
- **Попадания**: плотность ∝ N/(4π·R²) по углу разлёта (у цилиндра — пояс поперёк оси); ранит и бьёт стёкла по
  вероятности, оставляет выбоины.
