# S1. Паспорт по ТТХ (шаг 0)

ТЗ: `../local/steps/00-passport.md`. Данные: `../ref/passport.md`, источники `../ref/sources.md`. Правила области:
`strike.md`, `entity.md`, `defense.md`.

## Что изменилось после 3.5.0 (учесть)

- `WeaponSpec.charge` уже читают картинка и звук (через `S2C.Blast.weapon` и `client/fx/BlastSource`): поменял заряд —
  облако, шар, звук, слух и толчок следуют сами. Заряд ракеты — с 450 кг («Калибр») на БЧ «Томагавка» (WDU-36/B,
  ~120 кг PBXN-107 → ~150 кг ТНТ, оценка с отметкой; решение Артёма 18.10).
- `WeaponSpec.fuelAtImpact` есть (оценки облачной сессии: шахед 30 кг, ракета 280 кг); сверить с `../ref/passport.md`
  и оставить одну оценку с источником. Позже полёт (S2) может считать остаток по расходу — тогда поле становится
  выводом, а не числом.
- Данные двигателей для факела и звука уже лежат в `ClientWeaponSpec` (#352, #353). Паспорт — один источник: что
  нужно и серверу (тяга, расход, время работы, масса топлива), переезжает в `WeaponSpec`, клиент читает оттуда; дублей
  чисел не оставлять.

## Сверх шага 0

- **Скорости и высоты — игровые по умолчанию и настоящие настройкой `flight_speeds`** (Артём 21.10, `decisions.md`, «Скорости»): у каждой скорости и высоты
  полёта в паспорте два числа — игровое (нынешнее, с пометкой «не по физике») и настоящее с источником; саму настройку
  (`IncomingConfig`, SERVER) заводит S2; действие у цели и руководство берут настоящее. Сюда же — настоящие условия удара (скорость, угол) для S3/S5.
- **Паспорт ЗРК** (`defense/InterceptorSpec`) по 9М96 (Артём 21.10):
  масса, диаметр, тяга и время работы двигателя, наибольшая скорость, перегрузка, дальность, масса БЧ и ВВ, радиус
  взрывателя, источник у каждого числа, уверенность. Полёт по ним делает S6; здесь только данные и тесты на них.
- Размер «Ланцета» по ТТХ (1,65 м) — масштаб модели (`client-models.md`: настоящая величина).

## Проверка и готово

Как в шаге 0: поведение полёта не меняется (кроме заряда ракеты и размера «Ланцета» — их следствия видны в картинке и
звуке, кадры в PR); у каждого числа источник; `WeaponSpecTest` держит, что у каждого оружия есть все поля.
