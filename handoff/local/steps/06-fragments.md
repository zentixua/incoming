# Шаг 6. Осколки

Новый механизм. Карта кода: `code-map/warhead.md` §3 (`DebrisSpawner`, `Shatter`), `code-map/visual.md` §1
(`Fragments` — только у ядерки). Законы: `formulas.md` §7.

## Цель

Корпус боевой части дробится на тысячи осколков: начальная скорость — по Герни (быстрее звука), массы — по Мотту,
торможение воздухом; осколки летят дальше, чем ломает волна. Ранят по вероятности попадания (плотность падает как
1/R²), выбивают стёкла, оставляют выбоины в мягких блоках.

## Что меняется для игрока

- Рядом с взрывом опасно дальше радиуса волны: шахед и «Томагавк» ранят осколками на десятки–сотни метров (по
  вероятности, за укрытием — нет).
- Стёкла бьются не только волной, но и осколками (точками, а не все разом).
- Видно искры и трассы горячих осколков ночью; на стенах — выбоины.

## Сейчас

- Осколков нет; `DebrisSpawner` бросает обломки-блоки с постоянными скоростями; `DebrisEntity` ранит на
  min(16, max(2, fall·2 + v·3)).
- Клиентские `Fragments` (до 1200) есть только у ядерной пыли.

## Что сделать

1. Паспорт: масса корпуса БЧ и форма (цилиндр, сфера) — шаг 0; где данных нет — оценка: доля корпуса от массы БЧ
   (например, у «Града» 18.4 кг БЧ − 6.4 кг ВВ = 12 кг корпуса — по данным).
2. Сервер: осколки не сущностями — пучками (выборка N лучей по поясу разлёта, каждый — масса, скорость, торможение),
   под бюджетом (`work/`), с проверкой по сущностям в конусе и блокам по лучу (только готовые чанки); попадание —
   урон по кинетической энергии; блоки — выбоина (мягкие), стекло — разбить.
3. Клиент: видимые трассы и искры — частицы (твёрдые тела, `decisions.md` п. 4), число — по `FxBudget`; одно зерно
   с сервером, чтобы выбоины и трассы совпадали.
4. Тип урона — свой (осколки), с ключами языка.

## Не делать

- Не создавать тысячи сущностей; не грузить чанки по пути осколка.

## Проверка

- Юнит: скорость Герни для «Града» и шахеда против справочных диапазонов (1–2 км/с); дальность опасного осколка
  (скорость > порога поражения) по торможению; Мотт — среднее число осколков.
- GameTest: манекены на разных дистанциях за укрытием и без — доля попаданий по закону 1/R², за стеной ноль.
- Стенд: залп «Градов» — стоимость осколков в бюджете.

## Готово, когда

У каждого заряда с корпусом есть осколки по закону; урон и выбоины совпадают с клиентской картинкой.
