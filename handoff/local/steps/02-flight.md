# Шаг 2. Полёт

Самый большой шаг; можно резать на PR по изделию после общего закона. Карта кода: `code-map/flight.md`. Законы:
`formulas.md` §2. Данные: `passport.md`.

## Цель

Каждое изделие движется по своим ТТХ: тяга по времени, масса по выгоранию, сопротивление по числу Маха и плотности
воздуха на высоте, сила тяжести. Автопилоты остаются (их логика — игровая и уже проверенная), но их пределы
(перегрузка, скорость набора, разворот) берутся из ТТХ. Маршрут остаётся игровым по длине (время полёта в настройках),
скорость и высота — настоящие.

## Что меняется для игрока

- Шахед: крейсер ~150–185 км/ч низко, пике по балансу сил (~300 км/ч при 30°).
- «Ланцет»: настоящий размер 1.65 м (модель без ×1.5), 80–110 км/ч, пике до ~300.
- «Томагавк»: ускоритель по тяге и времени, потом ТРДД, ~250 м/с на 30–50 м над рельефом; горка и пике в конце — как
  сейчас по геометрии, но на настоящей скорости.
- «Град»: настоящий РДТТ (разгон до ~690 м/с за время работы), дальше баллистика с сопротивлением; на 20 км апогей ~7
  км (вне мира), полёт ~76 с; ближе ~5 км не стреляет (решение 2); рассеивание по данным.
- B-2: на 9–12 км вне мира со скоростью ~250 м/с; бомба падает с его скоростью под силой тяжести и сопротивлением
  (~50 с, удар ~500 м/с под ~64°) — пробитие — шаг 9.
- МБР: полоса входа по данным (скорость и угол), а не 20 км/с.

## Сейчас (главное)

- Шахед/ракета/«Ланцет»: постоянные скорости и коэффициенты в сущностях и автопилотах; `LaunchProfile.boost` —
  подобранный разгон.
- «Град»: дискретная парабола без тяги и воздуха, угол пакета 50°, скорость у среза — следствие дальности.
- B-2 на 170 блоках, 12 блоков/тик; бомба — постоянный разгон 0.3/тик до 12.5 (`BombDrop`).
- `FlightController.bankAngle` с g Minecraft (0.08) вместо 0.0245.
- Вне мира и чанки (`code-map/flight.md` §5–6) рассчитаны на нынешние скорости: `ChunkHold` держит только свой чанк и
  чанк впереди на 3×speed; `leavesTickingChunks` смотрит только конец шага; `ArrivalQueue` JUMP 64; пакеты FarFlights
  раз в 2/4 тика; `approach()` 256 блоков; `etaTicks` и загрузка районов.

## Что сделать

1. Общий интегратор точки с массой (сервер, чистый класс, юнит-тесты) по `formulas.md` §2 с атмосферой шага 1: тяга
   по закону двигателя из паспорта (РДТТ — профиль тяги и время; ТРДД — тяга и расход; винт — мощность × КПД / v),
   масса по расходу, сопротивление CdA·f(M)·ρ(h), тяжесть. Тик Minecraft — шаг интегрирования 1/20 с с подшагами,
   где разгон быстрый (РДТТ «Града» — подшаги, иначе ошибка скорости больше 1%).
2. Перевести каждое изделие на интегратор; автопилот задаёт желаемые тангаж/курс/тягу в пределах из паспорта, а
   скорость получается из сил. Константы автопилотов, которые зависят от скорости (реакция, просмотр рельефа, захват),
   выразить через скорость и время, а не блоки.
3. «Град»: баллистика с сопротивлением; угол возвышения пакета — по дальности из таблицы стрельбы, которую считает тот
   же интегратор (решение по углу, а не по скорости); рассеивание — по данным; ближе минимальной дальности — урезанная
   скорость схода с пометкой «не по физике» (решение Артёма 21.10, `next/S2-flight.md`), не отказ.
4. B-2 вне мира на высоте из паспорта; дальний вид должен его доставать (наклонная дальность > 12 км: `far_range`
   сейчас 8 км — поднять для B-2 или считать его видимость по угловому размеру); бомба — тем же интегратором.
5. МБР: полоса входа по данным (паспорт), согласовать код и комментарий.
6. Быстрые снаряды и чанки: держать чанки по отрезку пути за тик (все пересечённые колонки, только готовые);
   `leavesTickingChunks` — по отрезку; окна ожидания и загрузки районов — во времени (тики до цели), а не в блоках;
   `ArrivalQueue` и пакеты FarFlights — порог «телепорта» и частота от скорости; срабатывание по цели — в точке
   встречи, а не за speed+reachPad до неё.
7. «Ланцет»: модель 1.65 м (`tools/gen_models.py` `loiter()`, пересобрать), рамка столкновения.
8. Эталон сценариев (`runScenarioRecord`): записать заново; в PR — таблица, как изменились длительности и скорости по
   сценариям и почему (физика, а не ошибка).

## Не делать

- Не менять маршрутную логику, правила целей, приказы, пульт — это игра.
- Не ставить снаряду «скорость = константа» после интегратора; если автопилоту нужна постоянная скорость — он
  управляет тягой.
- Не грузить чанки синхронно на больших скоростях: только готовые (`Terrain`, `getChunkNow`).
